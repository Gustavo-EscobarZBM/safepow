# CLAUDE.md

## Stack
- `backend/`: Node.js + TypeScript, Jest para testes
- `web-panel/`: Next.js + Tailwind + shadcn/ui
- `mobile_app/`: Flutter (Dart)

## Workflow
Antes de realizar qualquer ação neste projeto (implementar feature, corrigir bug, revisar código, planejar mudança), verifique se alguma skill do plugin **Superpowers** se aplica e use-a. Em particular:
- Feature nova ou mudança de comportamento → `superpowers:brainstorming` antes de codar, depois `superpowers:writing-plans` se for multi-etapas.
- Bug, teste falhando, comportamento inesperado → `superpowers:systematic-debugging` antes de propor correção.
- Qualquer implementação de feature/bugfix → `superpowers:test-driven-development` (escrever teste antes do código).
- Ao concluir uma tarefa, antes de declarar como pronta → `superpowers:verification-before-completion`.
